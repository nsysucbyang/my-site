1. 中山大學全文資料庫
全文電子期刊查詢
查詢電子期刊的有無及其所在資料庫或位置。

2. Elsevier SDOS 電子期刊全文資料庫
SDOS提供Elsevier發行的1,100種電子期刊訂閱服務。1995後可查全文。

3. IEEE 電子期刊全文資料庫(IEEE/IEE)
IEEEXplore(原IEL)為美國電子電機工程師學會(IEEE)與英國電機工程師學會(IEE)出版品之電子全文資訊系統，內容包括IEEE與IEE自1988年以來出版之120種期刊、600種會議論文集、及875種IEEE工業標準。歷年資料皆可查全文。

4. IDEAL(AP)
Academic Press(AP)公司建置之電子期刊全文資料庫系統，提供AP所出版近二百種電子期刊，主題涵蓋理、工、醫、農、文、法、商各領域。1995年後可查全文。

5. LINK
LINK系統乃將Springer所出版的400多種期刊之電子版彙集一處提供線上檢索及瀏覽全文。1994後可查全文。

6. ACM Digital Library
可檢索及瀏覽所有ACM(Association for Computing Machinery) 出版品的目次及全文,但 Collected Algorithms, the Graduate Assistantship Directory. Computing Reviews(CREV)三種出版品則不包括在內 。

7. Ebscohost
內含Academic Search Fulltext Elite,本資料庫為一綜合性資料庫。

8. PQD(UMI)
下含ABI/INFORM資料庫。1995年後可查全文。

9. Wilson Select(FirstSearch)
屬OCLC FirstSearch中可線上瀏覽全文資料庫（其餘標示為全文資料庫者,所查到的全文皆來自WilsonSelect)。

Web of Sciencce
Science Citation Index Expanded
